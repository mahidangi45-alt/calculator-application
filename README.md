# 🧮 Calculator Application

## 📌 About the Project
This is a simple and user-friendly Calculator Application developed using HTML, CSS, and JavaScript as part of my internship Task 2.

It performs basic mathematical operations with a modern, colorful, and responsive user interface.

## ✨ Features
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Clear button to reset the calculation
- Division-by-zero error handling
- Responsive user interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start using the calculator.

## 🎯 Project Objective
The objective of this project is to improve my practical skills in HTML, CSS, and JavaScript by developing a functional calculator application.
